# Méthode d'apprentissage Embedded

Objectif : comprendre assez de théorie pour construire, mesurer et diagnostiquer un vrai montage.

## Boucle d'apprentissage

**objectif concret → notion courte → câblage/prototype → firmware minimal → observation → correction**

## Une nouvelle notion

1. définition simple ;
2. règle importante ;
3. exemple concret ;
4. erreur fréquente si utile ;
5. une seule manipulation ;
6. attendre le résultat.

## Ordre conseillé

Ne pas commencer par une architecture complexe.

Progression :
- sorties numériques ;
- entrées numériques ;
- temporisation ;
- PWM ;
- analogique ;
- capteurs ;
- UART ;
- I2C ;
- SPI ;
- états non bloquants ;
- persistance ;
- réseau seulement lorsqu'il apporte une vraie valeur.

## Validation

Practiced = fonctionnement obtenu avec aide.

Validated = l'utilisateur sait reconstruire ou expliquer la notion sans procédure détaillée et sait interpréter le résultat observé.
