# Décisions techniques

Conserver uniquement les choix qui auront encore de la valeur plus tard.

Format :

```text
Date:
Decision:
Context:
Reason:
Consequences:
```

Exemples de décisions pertinentes :
- choix Arduino Core vs ESP-IDF ;
- choix I2C vs SPI ;
- choix d'une tension d'alimentation ;
- ajout d'un RTOS ;
- adoption d'un protocole réseau.

Ne pas enregistrer les choix triviaux.
