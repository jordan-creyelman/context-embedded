# Checklist projet Embedded

- [ ] Le besoin est défini.
- [ ] La carte et les périphériques sont identifiés.
- [ ] Les tensions sont compatibles.
- [ ] Le brochage est documenté.
- [ ] Les limites de courant sont respectées.
- [ ] Le firmware compile.
- [ ] Les constantes ont des noms explicites.
- [ ] Les unités sont visibles dans les noms importants.
- [ ] Les erreurs critiques sont traitées.
- [ ] Le cas nominal fonctionne.
- [ ] Une panne importante a été testée.
- [ ] Les logs sont suffisants pour diagnostiquer.
- [ ] Aucun secret n'est dans le code.
- [ ] Les dépendances sont documentées.
- [ ] Le README explique comment reproduire le projet.
